# PuntoEncuentro
Punto Encuentro: plataforma web para reservar y administrar canchas deportivas. Incluye autenticación de jugadores y dueños, registro de canchas con precios personalizados, reservas de una hora sin solapamientos y gestión de estados. Desarrollada con React, Java y Spring Boot, aplicando los patrones Fachada, Strategy, Observer, State y Experto.
